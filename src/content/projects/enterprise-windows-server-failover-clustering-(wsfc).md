<h2>Enterprise Windows Server Failover Clustering (WSFC)</h2><p>Deployed high-availability server clusters to ensure continuous operational uptime for mission-critical application and database services.</p><h3>Key Features & Implementation</h3><ul><li><strong>Cloud Witness Quorum:</strong> Configured Azure/OCI Blob Storage cloud witness quorums to maintain cluster voting stability without physical site bias.</li><li><strong>Cluster Shared Volumes (CSV):</strong> Provisioned shared storage CSV volumes allowing concurrent VM access across cluster nodes.</li><li><strong>Live Migration Validation:</strong> Tested non-disruptive live migration of running virtual machine workloads during host node maintenance.</li></ul>
