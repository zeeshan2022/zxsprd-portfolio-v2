<h2>OCI Pre-Migration Application Modernization & Directory Cleansing</h2><p>Designed and led pre-migration infrastructure audit protocols to prepare on-premises legacy application servers and Active Directory objects for smooth cutover to Oracle Cloud Infrastructure (OCI).</p><h3>Key Features & Implementation</h3><ul><li><strong>Active Directory Cleansing:</strong> Automated stale user object identification, orphaned GPO removal, and schema alignment prior to directory sync.</li><li><strong>Runtime Stack Modernization:</strong> Evaluated WebLogic domain dependencies and database connection pools for Linux runtime compatibility.</li><li><strong>Security Control Mapping:</strong> Mapped local perimeter security policies to OCI Network Security Groups and FortiGate Virtual Appliances.</li></ul>
