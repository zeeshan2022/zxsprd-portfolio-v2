<h2>Automated Event Registration & Badge Printing Kiosk Infrastructure</h2><p>Deployed high-speed self-service check-in kiosks enabling event attendees to scan mobile QR passes and print entry badges in under 3 seconds.</p><h3>Key Features & Implementation</h3><ul><li><strong>Sub-Second QR Pass Parsing:</strong> Integrated high-speed 2D barcode scanners for instant attendee lookup against local database mirrors.</li><li><strong>Thermal Badge Printer Drivers:</strong> Authored custom direct USB thermal printer drivers delivering instantaneous, smudge-free badge generation.</li><li><strong>Live Attendee Cloud Sync:</strong> Synchronized local check-in records to central event cloud servers every 5 seconds for real-time headcount tracking.</li></ul>
