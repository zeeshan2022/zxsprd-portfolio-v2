<h2>Enterprise Privilege Access Management (PAM) & LAPS Deployment</h2><p>Eliminated pass-the-hash attack risks by deploying Windows LAPS to continuously randomize local administrator passwords across workstation fleets.</p><h3>Key Features & Implementation</h3><ul><li><strong>Automated Password Randomization:</strong> Configured GPO rules forcing 16-character randomized local admin passwords rotated every 30 days.</li><li><strong>AD-Vaulted Password Encryption:</strong> Restricted LAPS password read permissions strictly to authorized Tier-2 IT service desk personnel.</li><li><strong>Privilege Elevation Tracking:</strong> Configured audit alerts whenever a local administrator password was checked out from Active Directory.</li></ul>
