<h2>Network Monitoring System (Log-NMS) & SNMP Trap Aggregation</h2><p>Architected a centralized Network Monitoring System (NMS) to collect real-time performance metrics, bandwidth telemetry, and hardware alerts across corporate network assets.</p><h3>Key Features & Implementation</h3><ul><li><strong>SNMPv3 Encrypted Polling:</strong> Configured SNMPv3 authNoPriv/authPriv profiles across core firewalls, switches, and UPS systems for secure metric retrieval.</li><li><strong>Automated Threshold Alerting:</strong> Built automated email and web notification triggers for interface errors, packet drops, and high CPU/RAM utilization.</li><li><strong>Topology Mapping & Telemetry:</strong> Designed real-time visual rack and network topology diagrams mapping active link throughput.</li></ul>
