<h2>Experiential Exhibition Kiosk Remote Maintenance Tunnel</h2><p>Architected secure remote administrative access infrastructure enabling engineering teams to maintain field-deployed kiosks behind strict NAT firewalls.</p><h3>Key Features & Implementation</h3><ul><li><strong>WireGuard Encrypted VPN Mesh:</strong> Connected distributed exhibit terminals to a central secure management gateway over lightweight encrypted tunnels.</li><li><strong>Systemd Auto-Restart Watchdogs:</strong> Configured system watchdogs automatically rebooting kiosk software if memory leaks or freezes occur.</li><li><strong>Ansible Automated Deployment:</strong> Executed single-command remote software updates and config pushes across hundreds of field kiosk endpoints.</li></ul>
