<h2>Legacy Server Decommissioning & Data Sanitization</h2><p>Managed technical decommissioning workflows for legacy physical and virtual server infrastructure following strict data privacy standards.</p><h3>Key Features & Implementation</h3><ul><li><strong>NIST-Compliant Disk Wiping:</strong> Performed multi-pass DoD/NIST 800-88 compliant data sanitization on storage drives prior to disposal.</li><li><strong>Directory & DNS Purging:</strong> Removed orphaned server computer accounts, DNS A/PTR records, and stale service principal names (SPNs).</li><li><strong>Archive Preservation:</strong> Created encrypted cold backup snapshots of legacy system states before final compute resource termination.</li></ul>
