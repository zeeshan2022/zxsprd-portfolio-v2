<h2>FortiClient Endpoint VPN & Multi-Factor Authentication (Duo)</h2><p>Architected a secure remote access solution combining FortiClient SSL-VPN with Duo Proxy Multi-Factor Authentication (MFA) for enterprise users.</p><h3>Key Features & Implementation</h3><ul><li><strong>MFA-Protected Remote Access:</strong> Integrated Duo Proxy RADIUS authentication with Active Directory to enforce mandatory push notifications during login.</li><li><strong>Role-Based Jump Server Access:</strong> Restricted remote connections exclusively to segmented Jump Hosts based on user group authorization.</li><li><strong>Split-Tunneling & Encryption:</strong> Enforced AES-256 IPsec/SSL encryption and restricted direct internet access through corporate security inspection.</li></ul>
