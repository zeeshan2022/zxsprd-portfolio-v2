<h2>Oracle WebLogic Server Migration from Windows to Linux</h2><p>Architected and executed the platform migration of Oracle WebLogic Server application domains from Windows Server to Oracle Linux runtime environments.</p><h3>Key Features & Implementation</h3><ul><li><strong>Domain & Cluster Migration:</strong> Re-platformed WebLogic domain configurations, managed servers, and JDBC connection pools to Linux environments.</li><li><strong>Performance Optimization:</strong> Tuned Linux kernel parameters, JVM heap sizes, and garbage collection policies for high-concurrency enterprise applications.</li><li><strong>Automated Startup Scripts:</strong> Developed systemd service units for automated WebLogic server startup, health monitoring, and graceful shutdowns.</li></ul>
