<h2>Enterprise Infrastructure Cloud Migration to OCI</h2><p>Architected a comprehensive cloud migration strategy migrating an enterprise application stack (Oracle Database & WebLogic Server) to OCI with hybrid Active/Active Disaster Recovery architecture.</p><h3>Key Features & Implementation</h3><ul><li><strong>Zero Downtime Database Migration:</strong> Leveraged Oracle ZDM and Data Guard to achieve near-zero downtime database migration.</li><li><strong>Hybrid Cloud & Perimeter Security:</strong> Segmented VCN subnets managed via FortiGate firewalls, site-to-site IPsec VPN, and Duo Proxy MFA for secure administration.</li><li><strong>Regulatory Compliance:</strong> Ensured 100% compliance with UAE data residency laws while retaining local infrastructure as an Active DR site.</li></ul>
