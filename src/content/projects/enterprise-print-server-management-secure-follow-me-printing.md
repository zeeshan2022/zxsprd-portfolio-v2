<h2>Enterprise Print Server Management & Secure Follow-Me Printing</h2><p>Centralized print queue management and deployed secure release printing to eliminate unmonitored document printing across corporate offices.</p><h3>Key Features & Implementation</h3><ul><li><strong>Centralized Print Queues:</strong> Deployed a high-availability Windows Print Server managing all network multifunction devices (MFDs).</li><li><strong>GPO-Driven Deployment:</strong> Automated departmental printer mapping via Active Directory Group Policy preferences based on client location.</li><li><strong>Secure Release Authentication:</strong> Implemented PIN and RFID badge authentication on printers to ensure document privacy.</li></ul>
