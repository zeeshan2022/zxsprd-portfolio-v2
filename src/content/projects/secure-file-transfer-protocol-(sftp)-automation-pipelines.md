<h2>Secure File Transfer Protocol (SFTP) Automation Pipelines</h2><p>Architected automated, encrypted data pipeline transfers across internal business units and external financial entity partners.</p><h3>Key Features & Implementation</h3><ul><li><strong>SSH Public Key Authentication:</strong> Replaced password-based SFTP logins with 4096-bit RSA SSH public/private key pair authentication.</li><li><strong>Automated Ingestion & Cleanup:</strong> Built PowerShell scripts to automatically pick up, decrypt, ingest, and archive batch processing files.</li><li><strong>Granular Folder Isolation:</strong> Provisioned chrooted isolated user folder directories preventing directory traversal attempts.</li></ul>
