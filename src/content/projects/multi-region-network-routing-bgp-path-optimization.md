<h2>Multi-Region Network Routing & BGP Path Optimization</h2><p>Architected dynamic BGP routing protocols to manage traffic failover and path selection between corporate headquarters and cloud tenancies.</p><h3>Key Features & Implementation</h3><ul><li><strong>Dynamic BGP Peering:</strong> Established BGP routing sessions between FortiGate perimeter firewalls and cloud network gateways.</li><li><strong>Automated Route Failover:</strong> Configured route metrics and AS-Path prepending to ensure instant traffic rerouting during primary link failure.</li><li><strong>Route Summarization & Filtering:</strong> Implemented prefix lists and route maps to prevent transit routing and optimize routing table sizes.</li></ul>
