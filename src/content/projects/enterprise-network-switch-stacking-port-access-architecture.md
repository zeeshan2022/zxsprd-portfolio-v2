<h2>Enterprise Network Switch Stacking & Port Access Architecture</h2><p>Architected and hardened enterprise access-layer switch stacks to provide redundant bandwidth uplinks and isolated VLAN segmentation for corporate users.</p><h3>Key Features & Implementation</h3><ul><li><strong>Switch Stacking & Link Aggregation:</strong> Configured LACP trunking across switch units to eliminate single points of failure and double uplink throughput.</li><li><strong>Dynamic Port Security:</strong> Configured MAC-based port security and 802.1X authentication to block unauthorized rogue hardware connections.</li><li><strong>VLAN Access Hardening:</strong> Segmented voice, management, guest, and corporate desktop traffic using 802.1Q tags and explicit PVID assignments.</li></ul>
