<h2>Central Venue Interactive Exhibit Master Logging & Analytics System</h2><p>Architected central log aggregation pipelines collecting user interaction metrics and software diagnostic events from all active interactive terminals.</p><h3>Key Features & Implementation</h3><ul><li><strong>Real-Time Event Ingestion:</strong> Ingested thousands of user touch events, button clicks, and session start/end timestamps via lightweight REST endpoints.</li><li><strong>Kibana Management Dashboards:</strong> Built visual dashboards summarizing daily total venue interactions, average session times, and peak usage hours.</li><li><strong>Automated Exception Alerting:</strong> Flagged software unhandled exceptions and crashes instantly, triggering automatic remote restart commands.</li></ul>
