<h2>Multi-Tenant Cloud IAM Governance & Least-Privilege Audit</h2><p>Executed comprehensive cloud identity audits to eliminate over-privileged user access and enforce strict role-based access governance.</p><h3>Key Features & Implementation</h3><ul><li><strong>Global Admin Role Pruning:</strong> Reduced Global Administrator and Tenant Admin assignments to the absolute minimum necessary personnel.</li><li><strong>Custom Granular RBAC Roles:</strong> Replaced broad built-in admin roles with custom IAM roles scoped strictly to required resource groups.</li><li><strong>Automated Access Reviews:</strong> Configured periodic Entra ID Access Reviews requiring department heads to certify user group memberships quarterly.</li></ul>
