<h2>Datacenter Cable Management & Fiber Optic Patching Standards</h2><p>Overhauled server room physical cable topology to improve airflow, eliminate trace confusion, and streamline network port maintenance.</p><h3>Key Features & Implementation</h3><ul><li><strong>Color-Coded Subnet Patching:</strong> Standardized blue cabling for user networks, yellow for DMZ, red for firewall uplinks, and orange for OM4 fiber.</li><li><strong>Systematic Port Labeling:</strong> Applied ANSI/TIA-606-B compliant machine-printed labels to all switch ports, patch panels, and server interfaces.</li><li><strong>High-Density Fiber Enclosures:</strong> Installed OM4 LC fiber optic patch panels connecting server racks to core distribution switch stacks.</li></ul>
