<h2>Digital Forensics Incident Triage & Evidence Recovery</h2><p>Performed technical forensic analysis to identify malware persistence mechanisms and account breach vectors.</p><h3>Key Features & Implementation</h3><ul><li><strong>Forensic Disk Imaging:</strong> Created write-blocked bit-stream images of affected system drives for offline analysis.</li><li><strong>RAM Memory Analysis:</strong> Extracted volatile RAM artifacts using Volatility to detect un-injected DLL payloads.</li><li><strong>Incident Timeline Reconstruction:</strong> Reconstructed chronological attack timelines from Windows Security Event logs.</li></ul>
