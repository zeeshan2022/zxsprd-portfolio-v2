<h2>Enterprise Network Port Security & Dynamic ARP Inspection (DAI)</h2><p>Hardened Layer-2 network switch infrastructure against man-in-the-middle attacks and rogue network address spoofing.</p><h3>Key Features & Implementation</h3><ul><li><strong>DHCP Snooping Binding Database:</strong> Enabled DHCP Snooping to build a trusted IP-to-MAC address binding database across switch ports.</li><li><strong>Dynamic ARP Inspection (DAI):</strong> Configured DAI to validate ARP packets against the DHCP snooping table, dropping malicious spoofed ARP responses.</li><li><strong>Sticky MAC Port Security:</strong> Restricted access switch ports to maximum 2 learned MAC addresses to prevent rogue switch additions.</li></ul>
