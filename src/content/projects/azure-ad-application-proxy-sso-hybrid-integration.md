<h2>Azure AD Application Proxy & SSO Hybrid Integration</h2><p>Architected secure cloud publishing for on-premises internal portals, enabling SSO and MFA without exposing direct inbound firewall ports.</p><h3>Key Features & Implementation</h3><ul><li><strong>Inbound Port Elimination:</strong> Utilized outbound-only Azure AD App Proxy connector services to route external traffic securely.</li><li><strong>Kerberos Constrained Delegation (KCD):</strong> Configured KCD to seamlessly authenticate cloud-authenticated users to internal Windows-authenticated web apps.</li><li><strong>Conditional Access Binding:</strong> Enforced device compliance and geo-blocking policies on all external application access attempts.</li></ul>
