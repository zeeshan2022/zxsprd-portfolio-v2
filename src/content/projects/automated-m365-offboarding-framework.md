<h2>Automated Microsoft 365 Lifecycle & Offboarding Framework</h2><p>Designed and deployed an automated identity offboarding solution using PowerShell and Microsoft Graph API to replace manual administrative offboarding workflows.</p><h3>Key Features & Implementation</h3><ul><li><strong>14-Step Automated Workflow:</strong> Single-command execution disabling accounts, revoking active OAuth sessions, purging admin/group roles, wiping mobile devices, and resetting credentials.</li><li><strong>Automated Mailbox Migration:</strong> Seamlessly converts active user mailboxes into shared mailboxes and purges inbox rules to prevent auto-forwarding data leaks.</li><li><strong>Unattended Certificate Authentication:</strong> Built with OAuth 2.0 Certificate-Based Authentication for secure execution via Azure Entra ID app registrations.</li><li><strong>Bulk Processing & Reporting:</strong> Includes CSV batch ingestion and automated execution reporting (.CSV status logs and audit trails).</li></ul>
