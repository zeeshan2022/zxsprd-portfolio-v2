<h2>Enterprise Directory Synchronization & Azure AD Connect Hardening</h2><p>Configured hybrid identity synchronization using Azure AD Connect to securely bridge on-premises Active Directory with Microsoft 365.</p><h3>Key Features & Implementation</h3><ul><li><strong>Password Hash Sync (PHS) & Leaked Credential Detection:</strong> Enabled PHS with Leaked Credentials Detection to identify compromised corporate passwords automatically.</li><li><strong>Selective OU Sync Filtering:</strong> Filtered directory synchronization scope to sync approved user and group Organizational Units only.</li><li><strong>Staging Server Redundancy:</strong> Configured a secondary Azure AD Connect server in Staging Mode for rapid standby failover.</li></ul>
