<h2>Virtual Machine Hypervisor Host Cluster Upgrade & Maintenance</h2><p>Maintained hypervisor cluster security and performance by performing rolling OS upgrades and firmware patches across physical host nodes.</p><h3>Key Features & Implementation</h3><ul><li><strong>Live Workload Migration:</strong> Migrated active virtual machines sequentially off target hosts using Live Migration without interrupting user connections.</li><li><strong>Cluster-Aware Updating (CAU):</strong> Orchestrated CAU automated patch windows ensuring at least N+1 host redundancy remained active throughout updates.</li><li><strong>Post-Maintenance Host Validation:</strong> Verified host CPU, RAM, and SAN storage multipathing stability before returning hosts to the active cluster.</li></ul>
