<h2>CCTV & Physical Access Control System (PACS) Integration</h2><p>Designed and installed physical security systems combining IP camera surveillance and RFID/Biometric access control.</p><h3>Key Features & Implementation</h3><ul><li><strong>High-Retention Video Storage:</strong> Configured H.265 compression and RAID-5 NVR storage arrays for 90-day video retention.</li><li><strong>Door Access Controllers:</strong> Integrated magnetic locks and biometric card readers with central management software.</li><li><strong>Network Isolation:</strong> Placed physical security controllers on an air-gapped security network segment.</li></ul>
