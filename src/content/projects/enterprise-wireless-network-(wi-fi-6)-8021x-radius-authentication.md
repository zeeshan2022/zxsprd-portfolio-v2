<h2>Enterprise Wireless Network (Wi-Fi 6) & 802.1X RADIUS Authentication</h2><p>Designed and deployed high-density enterprise wireless networks featuring 802.1X certificate authentication and isolated guest network portals.</p><h3>Key Features & Implementation</h3><ul><li><strong>802.1X WPA3-Enterprise Security:</strong> Integrated Windows Network Policy Server (NPS) RADIUS authentication with Active Directory user/device credentials.</li><li><strong>Dynamic VLAN Assignment:</strong> Dynamically assigned connected wireless users to their respective departmental VLANs upon successful 802.1X login.</li><li><strong>Captive Portal Guest Network:</strong> Deployed an isolated Guest Wi-Fi SSID with bandwidth rate-limiting and self-service captive portal registration.</li></ul>
