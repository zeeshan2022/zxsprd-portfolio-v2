<h2>Interactive Kiosk Content Management System (CMS) Network</h2><p>Architected central device management and offline-first content sync pipelines across distributed interactive kiosk terminals.</p><h3>Key Features & Implementation</h3><ul><li><strong>Offline-First Content Caching:</strong> Built local database synchronization allowing kiosks to maintain full interactive functionality during network outages.</li><li><strong>Heartbeat Status Telemetry:</strong> Programmed real-time WebSocket ping monitoring alerting central operations of screen or hardware faults.</li><li><strong>Over-The-Air (OTA) Updating:</strong> Enabled secure remote application updates and media content pushes across all registered kiosk endpoints.</li></ul>
