<h2>Interactive Physical Reaction Game Button Wall System</h2><p>Architected physical reaction-game installations featuring wall-mounted heavy-duty illuminated buttons connected to custom microcontroller boards.</p><h3>Key Features & Implementation</h3><ul><li><strong>High-Speed Button Input Polling:</strong> Programmed microcontrollers polling physical button inputs at 1000Hz for instantaneous reaction time scoring.</li><li><strong>Addressable LED Ring Animations:</strong> Driven WS2812B LED rings surrounding each button to render dynamic countdown and target lighting patterns.</li><li><strong>Industrial-Grade Switch Debouncing:</strong> Implemented hardware and software debounce filters ensuring reliable long-term button press detection.</li></ul>
