<h2>Multi-Tenant Cloud IAM API Key Rotation & Credential Governance</h2><p>Hardened programmatic cloud access by enforcing automated secret rotation schedules for all application integration service accounts.</p><h3>Key Features & Implementation</h3><ul><li><strong>Automated 90-Day Key Rotation:</strong> Programmed scripts to generate, distribute, and validate new API access keys while deprecating stale credentials.</li><li><strong>Service Principal Secret Vaulting:</strong> Vaulted Azure App Registration and OCI API secrets directly in encrypted Key Vault repositories.</li><li><strong>Orphaned Credential Auditing:</strong> Built daily compliance scanners flagging active API keys unused for over 30 consecutive days.</li></ul>
