<h2>Multi-Factor Authentication (MFA) Soft-Token Migration & Support</h2><p>Hardened multi-factor authentication security by migrating users from vulnerable SMS text messages to push-notification soft tokens.</p><h3>Key Features & Implementation</h3><ul><li><strong>Number Matching & Location Display:</strong> Enforced Number Matching in Microsoft Authenticator prompts to prevent MFA fatigue attack exploitation.</li><li><strong>SMS Deprecation Campaign:</strong> Authored end-user setup guides and led transition workshops onboarding staff to smartphone authenticator apps.</li><li><strong>FIDO2 Hardware Key Provisioning:</strong> Deployed physical FIDO2 USB security keys for high-risk administrative users operating in sensitive environments.</li></ul>
