<h2>Central Experiential Media Server Master Deployment & Sync Vault</h2><p>Architected automated system disk backup and PXE recovery pipelines ensuring field media servers can be restored to factory staging in under 10 minutes.</p><h3>Key Features & Implementation</h3><ul><li><strong>Automated Disk Snapshot Images:</strong> Created compressed bare-metal system drive images stored on central local NAS backup vaults.</li><li><strong>PXE Network Bare-Metal Restore:</strong> Deployed local network boot recovery servers enabling field technicians to re-image corrupted servers over Ethernet.</li><li><strong>Version-Controlled App Configuration:</strong> Maintained automated Git repositories tracking application config files, display layouts, and IP mappings.</li></ul>
