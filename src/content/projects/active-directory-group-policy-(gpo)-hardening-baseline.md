<h2>Active Directory Group Policy (GPO) Hardening Baseline</h2><p>Standardized domain-wide security baselines across all Windows desktop endpoints and member servers using hardened Group Policy Objects.</p><h3>Key Features & Implementation</h3><ul><li><strong>Local Administrator Password Solution (LAPS):</strong> Automated unique, randomized local administrator account passwords with AD-vaulted recovery.</li><li><strong>CIS Security Benchmark Enforcement:</strong> Applied Center for Internet Security (CIS) OS hardening rules restricting SMBv1, PowerShell v2, and NTLMv1.</li><li><strong>Centralized Audit Policies:</strong> Configured Advanced Audit Policy settings to log privilege usage, account logon events, and process creation.</li></ul>
