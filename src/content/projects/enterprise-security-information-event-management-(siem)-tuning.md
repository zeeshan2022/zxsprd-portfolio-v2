<h2>Enterprise Security Information & Event Management (SIEM) Tuning</h2><p>Optimized security event correlation rules within central SIEM logs to increase threat detection fidelity and reduce SOC alert fatigue.</p><h3>Key Features & Implementation</h3><ul><li><strong>Custom Event Correlation Rules:</strong> Authored correlation rules detecting multiple failed logons followed by immediate successful administrative privilege use.</li><li><strong>False Positive Suppression:</strong> Suppressed benign system noise and automated service account alerts through precise white-scoping.</li><li><strong>Log Ingestion Parsing:</strong> Developed custom regex log parsers for non-standard application logs to map fields to standard SIEM schemas.</li></ul>
