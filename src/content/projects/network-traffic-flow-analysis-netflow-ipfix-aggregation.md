<h2>Network Traffic Flow Analysis & NetFlow / IPFIX Aggregation</h2><p>Gained deep Layer-3/4 traffic visibility across corporate WAN links by exporting NetFlow v9 telemetry to a centralized collector.</p><h3>Key Features & Implementation</h3><ul><li><strong>NetFlow v9 Export Configuration:</strong> Configured FortiGate interfaces to export flow records tracking source/destination IPs, ports, and byte counts.</li><li><strong>Top Talker Identification:</strong> Built automated dashboards flagging high-bandwidth consumers, non-standard port traffic, and peer-to-peer streams.</li><li><strong>Anomaly Detection:</strong> Set up baseline traffic alerts detecting unusual data egress spikes indicative of potential data exfiltration.</li></ul>
