<h2>Enterprise BitLocker Encryption & Recovery Key Vaulting Architecture</h2><p>Designed and deployed automated BitLocker drive encryption across enterprise laptop fleets to protect data on lost or stolen mobile devices.</p><h3>Key Features & Implementation</h3><ul><li><strong>Automated Enrolment & TPM Binding:</strong> Enforced mandatory hardware-bound TPM 2.0 full-disk encryption during device staging.</li><li><strong>Active Directory Key Backup:</strong> Automated real-time BitLocker recovery key escrow to Active Directory domain controller objects.</li><li><strong>Centralized Encryption Auditing:</strong> Built PowerShell audit scripts to continuously report fleet-wide compliance status.</li></ul>
