<h2>Enterprise Endpoint Software Inventory & Unapproved App Audit</h2><p>Audited software installations across workstation fleets to identify unauthorized applications and enforce corporate software baselines.</p><h3>Key Features & Implementation</h3><ul><li><strong>Automated Software Discovery:</strong> Executed central inventory scanning scripts parsing installed software registry keys across domain endpoints.</li><li><strong>Unapproved App Flagging:</strong> Cross-referenced installed application lists against approved corporate software catalogs to flag unauthorized apps.</li><li><strong>Silent Automated Removal:</strong> Built automated PowerShell removal scripts to silently uninstall unauthorized torrent clients and browser extensions.</li></ul>
