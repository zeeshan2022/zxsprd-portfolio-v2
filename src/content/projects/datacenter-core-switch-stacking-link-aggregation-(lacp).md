<h2>Datacenter Core Switch Stacking & Link Aggregation (LACP)</h2><p>Architected a resilient network distribution core by stacking physical switches into unified high-speed logical switch backbones.</p><h3>Key Features & Implementation</h3><ul><li><strong>Hardware Backplane Stacking:</strong> Grouped core switches using dedicated high-speed stacking cables to share unified control planes.</li><li><strong>Multi-Chassis LACP Trunking:</strong> Configured cross-stack LACP link aggregation channels to distribute traffic across physical switch units.</li><li><strong>Rapid Spanning Tree (RSTP) Tuning:</strong> Hardened RSTP BPDU Guard and Root Guard settings to prevent rogue switch insertion loops.</li></ul>
