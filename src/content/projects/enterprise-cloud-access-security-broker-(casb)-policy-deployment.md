<h2>Enterprise Cloud Access Security Broker (CASB) Policy Deployment</h2><p>Implemented cloud application governance to gain visibility into unapproved SaaS usage and prevent corporate data exfiltration.</p><h3>Key Features & Implementation</h3><ul><li><strong>Shadow IT Discovery:</strong> Integrated firewall traffic logs into CASB to discover, score, and rank unapproved cloud web applications.</li><li><strong>Conditional App Control:</strong> Applied real-time session controls blocking document downloads onto unmanaged personal devices.</li><li><strong>Malware Upload Inspection:</strong> Enabled real-time file scanning for inbound cloud uploads to stop cloud repository malware contamination.</li></ul>
