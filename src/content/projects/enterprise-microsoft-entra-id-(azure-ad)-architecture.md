<h2>Enterprise Microsoft Entra ID (Azure AD) Architecture</h2><p>Configured and optimized corporate Microsoft Entra ID identity infrastructure to secure cloud application authentication across all staff users.</p><h3>Key Features & Implementation</h3><ul><li><strong>Conditional Access Enforcement:</strong> Formulated location, device-health, and risk-based MFA enforcement rules for cloud portal access.</li><li><strong>Single Sign-On (SSO) Integration:</strong> Integrated third-party SaaS platforms with Entra ID via SAML 2.0 and OAuth 2.0 for unified credential management.</li><li><strong>Privileged Identity Management (PIM):</strong> Restricted administrative role activation to time-bound, approval-required just-in-time access windows.</li></ul>
