<h2>Enterprise Password Governance & Password Manager Rollout</h2><p>Designed and managed the end-to-end deployment of 1Password Enterprise across corporate desktop and mobile endpoints to eliminate unencrypted password storage.</p><h3>Key Features & Implementation</h3><ul><li><strong>SSO & 2FA Integration:</strong> Streamlined user onboarding by configuring Single Sign-On via Microsoft 365 and enforcing mandatory 2FA.</li><li><strong>Vault Architecture:</strong> Provisioned isolated individual personal vaults and department-specific shared vaults (HR, Finance, IT) with fine-grained RBAC access permissions.</li><li><strong>Security Lifecycle Management:</strong> Standardized quick-access desktop workflows and executed legacy credential method decommissioning.</li></ul>
