<h2>Central Experiential Media Server Monitoring Dashboard</h2><p>Developed remote telemetry monitoring solutions giving engineering teams real-time visibility into the performance of remote exhibit media servers.</p><h3>Key Features & Implementation</h3><ul><li><strong>GPU & System Metric Collection:</strong> Deployed lightweight background agents recording GPU temperature, VRAM usage, and video frame drop rates.</li><li><strong>Grafana Telemetry Visualization:</strong> Built unified web dashboards displaying live operational status across all active exhibit installations.</li><li><strong>Automated Alert Escalation:</strong> Configured instant notification webhooks alerting technicians if server temperatures or memory limits cross safety thresholds.</li></ul>
